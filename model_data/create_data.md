## 2. 시스템 작동 로직 (RAG)

```
[사용자 입력] ──▶ [독소조항 검출] ──▶ [임베딩 검색] ──▶ [정밀 재순위화] ──▶ [리포트 생성]
  계약서 조항       KoELECTRA-Small      bge-m3 모델        KoELECTRA-Base       LLM 추론
  또는 파일 첨부
```

### Step 1 — 진단 (Input)

사용자 계약서 조항 문구 직접 입력 또는 계약서 문서 파일 첨부

- 파일 첨부 시: LLM이 조항 분류 선행 후 딥러닝 모델에 전달

### Step 2 — 대조 (Search)

**1차 독소조항 검출** (KoELECTRA-Small)

- 학습된 모델이 입력된 조항의 독소 여부 1차 판별

  **2차 임베딩 검색** (bge-m3, 기성 모델 그대로 사용)

- 불리 조항: '불공정' 판결이 난 실제 사례 탐색
- 유리 조항: 해당 상황에 가장 적합한 '표준/안전' 문구 확보
- 근로기준법: 해당 독소조항이 위반한 법령 조항 검색

  **3차 정밀 재순위화** (KoELECTRA-Base)

- 임베딩 검색 결과를 정밀 심사하여 사용자 조항과 가장 유사한 불리/유리/근로기준법 조항 최종 추출

### Step 3 — 처방 (Reasoning)

LLM이 검색된 '판단 근거'와 '관련 법령'을 종합하여 맞춤형 분석 리포트 생성

## 3차 정밀 심사 딥러닝 모델 데이터 생성(모델 학습 데이터)

### 라벨 1(정답) 독소조항 생성 가이드

1. 첨부한 파일들을 전부 파악 할 것.
2. 첨부파일 중 샘플 양식과 동일한 방식으로 독소조항 생성(아래 주의사항 필독)
3. 독소조항 생성시 주의사항
   - 첨부파일 근로기준법(통합내용) 에서 랜덤으로 100개 추출(조항끼리 겹치지 않게 각 1개씩 총 100개)
   - 첨부파일 판례 데이터에서 실제 판례(요약) 랜덤으로 내용 100개 추출(위와 동일하게 각 1개씩 총 100개)
   - 추출한 총 200개의 근로기준법 + 판례 데이터에 맞는 각기 다른내용의 독소조항 생성
   - 다양한 분야의 실제 근로계약서에서 사용할 법한 문체로 전문가가 작성한 문장 처럼 보일게 작성 할 것
   - 위에서 추출한 총 200개의 판례 + 근로기준법 에 일치 하는 독소조항이면서 내용자체가 너무 교묘해서 이게 위반 사례인가? 할 정도로 교묘해야됨(단 판례 독소조항 작성시 판례 내용에 너무 동일하게 맞추려 하지 않아도 됨(판례내용을 파악해서 근로기준법에 위반된 내용으로 독소조항을 작성하면 판례가 근거자료가 될 정도면 됨). 독소조항 내용이 판례 내용과 적당한 연관성이 있으면서, 파악했을때 교묘하지만 근로기준법 위반 사항 일 것, 단 조항은 전문가가 작성한 것처럼 근로계약서 문체로 작성되어야 함.)
   - 파이썬 코드로 단어 조합을 반복문 사용하여 단어 짜집기 하지 말 것!!
   - 추출해온 각기 다른 법령 / 판례 에 1:1 맞춤으로 실제 전문가가 작성한 조항처럼 포괄적이면서 교묘하게 작성되었지만 실제 판례가 근거가 되는 독소조항이거나, 근로기준법 에 위반되게 작성 되어야 함.
   - 독소조항 내용은 60~70자 이내로 장황한 설명 말고, 핵심 본론 내용으로만 실제 계약서 문체로 작성 할 것.
   - 모든 독소조항 내용은 동일내용이 2개이상 겹치지 않아야 하며, 2개 이상 겹치 때 각 법령 내용은 독소조항과 연관이 있지만 서로 달라야함.
     (단, 법령은 독소조항 내용이 달라도 겹칠수 있으므로 최대 5개 까지만 허용, 판례 약 2400개, 근로기준법 약 400개 조항이므로 다양하게 활용하면 5개 미만으로 겹치가 가능함.)
   - 실제 계약서에는 회사는 또는 갑은, 근로자 또는 을을 , 마케팅 팀은, 등등 앞에 무언가 붙지만 그렇게
     작성하게되면 딥러닝 모델은 앞글자만 무한반복 되는 문구들만 암기하게됨 하여, 학습데이터셋에서는 아래처럼 본문만 핵심내용으로 작성 해야하며, 누가봐도 독소조항처럼 보이지않게 매우 교묘해야함.
     (예시:"업무상 과실로 발생한 손실액에 대하여 최초 포인트로 차감 후 상여금 지급시 반영 하는것에 근로자는 사전 동의한 것으로 간주한다.)

- 참고사항

* 출력 파일은 CSV 형태 인코딩 옵션(encoding="utf-8-sig") 으로 할 것
* 샘플 조항 내용은 참고하되, 특정부서, 회사내에서 , 경비실에서 특정단어 사용금지,
  실제 계약서에서는 특정 장소에서 처럼 공통 사항으로 대부분 작성됨.
* 판례 데이터가 너무 오래전 내용도 있어서 판례에 있는 근로기준법 조항이 현재와 다를 수 있으므로
  (판례 내용의 핵심을 파악해서 현재 근로기준법 조항에 맞추어야 함. / 예: 판례내용: 근로기준법 제22조 위반, 그때 당시 22조와 현재 22조 내용이 다를수 있음 필히 판례 내용의 핵심 위반사항을 파악 후 현재 근로기준법 조항으로 참고해야함!! )
* 조항 가장 앞에 근로조건은, 근로자는, 근로자가 등 해당 내용 없이 바로 본론으로 들어갈 것
  (예: "근로조건의 기준이 최저 수준임을 이해하며, 회사의 경영 악화 시 임금 및 모든 근무 조건의 단독 조정에 동의한다.", "업무상 산재 발생 시, 근로자 귀책 요인이 있다고 회사가 판단하면 근로자가 보험금 청구 비용을 부담하기로 한다.")
* 내용의 법령은 판례(요약) 및 근로기준법(통합내용)을 그대로 사용해야함, 사유는 50자 이내로 핵심 내용만 요약할 것.

### 라벨 2(오답) 독소조항 생성 가이드

1. 첨부한 파일들을 전부 파악 할 것.
2. 첨부파일 중 샘플 양식과 동일한 방식으로 독소조항 생성(아래 주의사항 필독)
3. 독소조항 생성시 주의사항
   - 첨부파일 근로기준법(통합내용) 에서 랜덤으로 100개 추출(조항끼리 겹치지 않게 각 1개씩 총 100개)
   - 첨부파일 판례 데이터에서 실제 판례(요약) 랜덤으로 내용 100개 추출(위와 동일하게 각 1개씩 총 100개)
   - 추출한 총 200개의 근로기준법(통합내용) + 판례(요약) 데이터와 비슷하지만 핵심 내용은 다른게 하여 각기 다른내용의 독소조항 생성
   - 다양한 분야의 실제 근로계약서에서 사용할 법한 문체로 전문가가 작성한 문장 처럼 보일게 작성 할 것
   - 위에서 추출한 총 200개의 판례 + 근로기준법과 무언가 비슷하지만 핵심 내용은 다른 독소조항이면서 내용자체가 너무 교묘해서 이게 위반 사례인가? 할 정도로 독소조항 내용은 교묘해야됨(단 판례 독소조항 작성시 판례 내용과 내용이 완전 다른 독소조항 내용도 필요하고, 또는 판례 내용과 무언가 비슷하지만 자세히 파악해보면 의미가 완전 다른 내용의 독소조항도 필요함. 조항은 전문가가 작성한 것처럼 근로계약서 문체로 작성되어야 함.)
   - 파이썬 코드로 단어 조합을 반복문 사용하여 단어 짜집기 하지 말 것!!

   - 독소조항 내용은 100자 이내로 장황한 설명 말고, 핵심 본론 내용으로만 실제 계약서 문체로 작성 할 것.
   - 모든 독소조항 내용은 동일내용이 2개이상 겹치지 않아야 하며, 2개 이상 겹치 때 각 법령 내용은 독소조항과 키워드는 비슷하지만 전체적으로 의미가 다른 독소조항으로 1개, 또는 완전 키워드도 아예 다른 누가봐도 연관성 없는 매칭이 하나도 안되는 다른 독소조항 으로 1개 이런식으로 맞출 것.
   - 첨부한 데이터는 판례 약 2400개, 근로기준법 약 400개 조항이므로 다양하게 활용하면 라벨 0 에선 법령이 하나도 겹치지 않게 작성 가능하므로 라벨 0(오답) 에서는 법령 끼리 단 한개도 겹치면 안됨.
