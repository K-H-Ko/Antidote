# ⚖️ [Progress Report] 근로계약 법적 근거 정밀 매칭 시스템 모델 학습 과정

모델 학습 목적:
임베딩 모델이 추출한 법령 및 판례 후보군 중, 특정 독소조항의 위반 여부를 입증할 최적의 근거를 확정하는 **'Cross-Encoder 기반 정밀 매칭 모델'**의 개발 및 최적화.

---

## 1. 모델 후보군 탐색

프로젝트 초기, 최적의 베이스 모델 선정을 위해 판례 일부와 근로기준법을 활용한 **3,000개의 데이터셋**을 구축, 임베딩 모델이 찾아온 근거자료에서 **재순위화(Re-ranking)** 를 위해 최적의 변별력을 보여줄 베이스 모델을 선정하기 위해 인코더 모델 3종을 비교 검증했습니다.

### 📊 모델별 기초 제원 및 기초 검증 결과 비교

| 지표              |   KoELECTRA (Base)    |    **RoBERTa (Base)**     |    mDeBERTa (Base)     |
| :---------------- | :-------------------: | :-----------------------: | :--------------------: |
| **모델 용량**     |       약 450MB        |       **약 443MB**        |        약 550MB        |
| **최고 F1-Score** |        0.8008         |        **0.8525**         |         0.8485         |
| **최고 Accuracy** |        0.7966         |        **0.8745**         |         0.8725         |
| **특이 사항**     | 위험 요소 포착력 우수 | **법적 매칭 정밀도 우위** | 성능은 괜찮으나 무거움 |

> **💡 전략적 선택:** `klue/roberta-base`
> 검색된 여러 법적 근거 중 실제 위반 조항과 연결되는 '진짜 정답'을 골라내는 **정밀도(Precision)**가 뛰어나며, 파이프라인의 효율성을 고려할 때 가장 균형 잡힌 성능을 보여줌.
> (mDeBERTa 모델도 성능은 괜찮았으나 너무 무거워 출력이 느린 단점 발견)

## 2. 초기 모델 검증 및 한계점 분석

선정된 RoBERTa 모델을 대상으로 테스트 검증을 하다보니, 특정 지표는 우수했으나 실제 서비스 적용 시 **오탐(False Positive) 발생률이 예상보다 높음**을 확인했습니다.

- **문제 진단:** 3,000개의 초기 데이터셋만으로는 복잡한 법리적 인과관계를 모두 학습하기에 한계가 있음.
- **해결 방안:** 검색된 후보군 중 '진짜 정답'을 가려내는 변별력을 높이기 위해, 근로기준법 전 조항과 대규모 판례 테마를 결합한 **'데이터 재건축'** 결정.

---

## 3. 7,000개 데이터셋 구축

오탐률을 획기적으로 낮추기 위해 실제 판례 및 근로기준법 기반의 원천 데이터를 정밀 정제했습니다.

### ① 법리적 테마 클러스터링 및 정밀 요약

- API 승인을 통해 확보한 실제 판례 **약 2,400건**을 200자 이내 핵심 위반 내용으로 요약.
- 2,400개 판례를 조항별 상황에 맞춰 재분류 + 판례별 테마 구분 후 테마별 대표 판례를 추출하여 **800개의 핵심 정수**로 압축. (800개 학습으로 2,400개 판례 전체 대응 가능 구조 완성)

### ② 근로기준법 전수 매칭 및 도메인 확장

- 근로기준법 제1조~116조(약 420개 조항) 전 조항에 대한 정답/오답 데이터 **1,200건** 생성.
- 판례와 법령이 결합된 독소조항 기초 데이터셋 **2,000건** 구축.
- 다양한 산업 분야의 교묘한 독소조항 시나리오를 설계하여 **2,000건 추가 증강**.
- 초기 데이터(3,000건) + 증강 데이터(4,000건)를 결합하여 **총 7,000건의 데이터셋** 구축.

## 4. 시스템 정밀 학습 (7,796 Sets)

7,796개의 데이터셋으로 아래 기술을 활용하여 최종 학습.

### 🔍 주요 기술적 통찰

1. 초기 전체 레이어 고정 상태에서 상위 레이어(10, 11번)를 개방하는 것만으로도 정확도가 **17%~25%p** 가량 폭발적으로 상승하는 것을 확인.
2. 스케줄러 `Plateau` 대비 `Cosine` 이 학습 후반부의 미세한 법리적 차이를 학습하는 데 더 적합함을 확인.
3. 전 레이어를 개방하되, 층별 학습률 차등를 적용하여 기존 한글 지능 보존과 새로운 법리 습득의 최적화 도모.
4. Focal Loss(하드 네거티브 집중 학습)와 R-Drop(논리적 일관성 강제)을 결합하여 최대 효율의 모델 학습 진행.

### 📈 임계값별 성능 분석 (PR/F1 Curve)

## 6. 결론 및 향후 전망

본 프로젝트를 통해 개발된 Cross-Encoder 모델은 93% 이상의 F1-Score를 기록하며, 검색된 법적 근거의 타당성을 전문가 수준으로 검증할 수 있는 지능을 갖춤.

1.  **LLM 리포트 품질 혁신:** 본 모델이 '적합(Label 1)'으로 판정한 근거만을 최종 LLM에 전달함으로써, 근거 없는 답변을 생성하는 환각(Hallucination) 현상을 원천 차단하고 리포트의 법적 전문성을 극대화.
2.  **신뢰도 기반 운영 전략:** 최적 임계값 0.54를 기준으로, 높은 확신도를 가진 결과는 즉시 리포트에 인용하고 0.85 미만의 결과는 보조 참고 자료로 분류하는 등 차등화된 운영 방식을 통해 서비스 안정성을 확보할 예정.
3.  **지속적 고도화:** 향후 실전 운영 과정에서 발생하는 고난도 법리 해석 사례를 지속적으로 모니터링하여 학습 데이터에 피드백함으로써, 매칭률 99% 이상의 완벽한 '법률 추론 특화 모델'로 진화시켜 나갈 계획.
